# Team task folders

One folder per person. Each has one index file named after the person and one Markdown file per task.

| Person | Index |
|---|---|
| Hamza | [hamza/hamza.md](hamza/hamza.md) |
| Haris | [haris/haris.md](haris/haris.md) |
| Hamna | [hamna/hamna.md](hamna/hamna.md) |

Task files are named `YYYY-MM-DD-weekday-topic.md` so they sort by date.

Keys, tokens and passwords are never kept here.
